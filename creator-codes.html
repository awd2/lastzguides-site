Support Guide • Updated October 2026 • Last Z Guides

Quick Answer

A Last Z creator code supports a creator through your official-site top-ups. Bind one free on the official Gold Bar website for a one-time 100 Z-Points achievement; a payment after binding unlocks another 200 Gold Bars + 200 Z-Points. It is not a gift code and does not work in the Gift Center.

How to Bind a Creator Code

  1. Open Creator Code. Open the Creator Code page on the official Gold Bar website.
  2. Log in. Log in with your Player ID.
  3. Bind one code. Enter a creator code from the list above and bind it. The page shows Creator code linked when it succeeds.
  4. Claim the achievement. Open Task Rewards → Achievement and claim Successfully bind a Creator Code, then collect the reward from your in-game mailbox.

FAQ

Can I support more than one creator at once?

No. You can link one creator code at a time. Change Code replaces the linked code; Unbind removes it.

Can I get the binding reward again by switching codes?

No. Achievement missions can only be completed once. Switching or rebinding does not make the 100 Z-Points achievement available again.

Does supporting a creator make top-ups more expensive?

No. While the code is active, the creator receives a portion of your official-site top-up revenue at no extra cost to you. Binding itself is free.

What happens when a creator code expires?

The site asks you to bind a code again. Pick a current code from the list; the 100 Z-Points achievement doesn't repeat.

How do creators get a Creator Code?

Only official Last Z content creators get one; the team picks them through Community Outpost recruitment events announced on the official Discord. Creators earn rewards when players top up on the official site with their code.
